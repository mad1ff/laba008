**Условие:**  
Рассматриваются символьные последовательности длины 6 в пятибуквенном алфавите {K, A, T, E, P}. Сколько существует таких последовательностей, которые начинаются с буквы P и заканчиваются буквой K?

**Решение:**  
- Первая буква фиксирована — P (1 вариант)
- Последняя буква фиксирована — K (1 вариант)
- Остальные 4 позиции могут быть любыми из 5 букв

Количество = 1 × 5 × 5 × 5 × 5 × 1 = 5⁴ = 625

**Ответ:** 625

**Условие:**  
Значение выражения 216⁶ + 216⁴ + 36⁶ − 6¹⁴ − 24 записали в системе счисления с основанием 6. Сколько различных цифр содержит эта запись?

**Решение:**  
216 = 6³, 36 = 6²

216⁶ = (6³)⁶ = 6¹⁸  
216⁴ = (6³)⁴ = 6¹²  
36⁶ = (6²)⁶ = 6¹²

Выражение: 6¹⁸ + 6¹² + 6¹² − 6¹⁴ − 24 = 6¹⁸ + 2·6¹² − 6¹⁴ − 24

Вычисляем значение и переводим в 6-чную систему счисления.

## Задача 1

**Условие:**  
Реализовать замыкание для поиска среднего арифметического всех переданных аргументов. Замыкание должно накапливать числа при каждом вызове и возвращать текущее среднее. При вызове без аргумента — возвращать среднее без добавления нового числа.

**Решение:**  
Создана функция `make_average()`, которая возвращает замыкание `average(value=None)`. Внутри замыкания хранится список `numbers`, в который добавляются переданные числа. При вызове без аргументов возвращается среднее арифметическое всех накопленных чисел. Если чисел нет, возвращается 0.

**Результат работы:**

   Добавлено 50, текущее среднее: 30.0

Финальное среднее: 30.0

## Задача 2

**Условие:**  
Создать декоратор с опциональными параметрами для проверки аргументов функции на тип и диапазон значений. Декоратор должен поддерживать параметры:
- `type_check` — ожидаемый тип аргумента
- `min_value` — минимальное допустимое значение
- `max_value` — максимальное допустимое значение

Реализован декоратор `@validate_args(type_check=None, min_value=None, max_value=None)`. Декоратор проверяет все позиционные и именованные аргументы. При нарушении условий выбрасывается `TypeError` (ошибка типа) или `ValueError` (выход за диапазон).

## Вариант 8
Тема: Генераторы в Python
Задача
Условие:
Разработать генератор, который применяет заданную функцию к каждому элементу последовательности N раз и возвращает только те элементы, которые изменились значительно (зависит от N и типа данных). Применить к генератору функции map, filter, reduce. Написать тесты с использованием pytest.

Решение
1. Реализация генератора
Создана функция-генератор generator_filter(sequence, func, n, threshold=0.5):

Принимает последовательность, функцию, количество применений N и порог значительного изменения

Для каждого элемента применяет функцию N раз

Проверяет, изменился ли элемент значительно (относительное изменение > порога)

Для чисел используется формула: |результат - исходное| / |исходное| > порог

Для строк используется относительное изменение длины

Возвращает только значительно изменившиеся элементы

2. Применение map, filter, reduce (Rare уровень)
map: применён для форматирования вывода результатов

filter: применён для отбора результатов, больших 100

reduce: применён для суммирования результатов

3. Тестирование (Medium уровень)
Написаны 8 тестов с использованием pytest:

test_basic_numbers – проверка работы с числами

test_no_significant_change – проверка, что незначительные изменения не возвращаются

test_strings – проверка работы со строками

test_with_map – проверка совместной работы с map

test_with_filter – проверка совместной работы с filter

test_with_reduce – проверка совместной работы с reduce

test_empty_sequence – проверка на пустую последовательность

test_different_threshold – проверка разных порогов

class Rectangle:
    def __init__(self, a, b):
        self.a = a
        self.b = b
    def area(self):
        return self.a * self.b
    def perimeter(self):
        return 2 * (self.a + self.b)
    def info(self):
        return f"Прямоугольник: a={self.a}, b={self.b}"
triangle.py — класс для расчёта треугольника (формула Герона):

python
class Triangle:
    def __init__(self, a, b, c):
        self.a, self.b, self.c = a, b, c
    def area(self):
        s = (self.a + self.b + self.c) / 2
        return (s * (s - self.a) * (s - self.b) * (s - self.c)) ** 0.5
    def perimeter(self):
        return self.a + self.b + self.c
    def info(self):
        return f"Треугольник: a={self.a}, b={self.b}, c={self.c}"
trapezoid.py — класс для расчёта трапеции:

python
class Trapezoid:
    def __init__(self, a, b, h):
        self.a, self.b, self.h = a, b, h
    def area(self):
        return (self.a + self.b) / 2 * self.h
    def perimeter(self):
        return self.a + self.b + 2 * self.h
    def info(self):
        return f"Трапеция: a={self.a}, b={self.b}, h={self.h}"
